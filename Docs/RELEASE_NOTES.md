# Third Age for Mac 0.1.0 beta 1

An unofficial native Mac helper for installing Third Age: Total War 3.2 from Gigantus's two-part compilation into the Steam Mac version of Medieval II with Kingdoms.

## Included

- A universal Mac app, built for Apple Silicon and Intel, targeting macOS 12 or later.
- Game-folder detection, download verification, progress, cancellation, a launch button, a Desktop alias, and an offline help guide.
- Direct extraction without Wine or running Windows installers.
- Lowercase paths, Mac launch configuration, and removal of map and empty sound caches.
- Staging and verification before the new mod folder is installed; existing Third Age folders are refused.

## Validation

Full real-archive installation passed 18,961 publisher file checksums. Cancellation, cleanup, parser safeguards, and preservation of an existing neighboring mod were tested. A manual installation using the approach was reported working on Apple Silicon.

## Beta limitations

- Ad-hoc signed only; not Developer ID signed or notarized. macOS may require per-app approval.
- Intel gameplay, older macOS versions, full campaigns, and multiplayer need testing.
- Some game launches may require selecting Third Age in the Feral launcher's Advanced Options; the guide explains this.
- No gameplay balance changes, automatic updates, upgrade/replace operation, or alternate Third Age editions.
- No game or mod assets are included. Players must own the Mac game and obtain the two supported mod downloads separately.
