UNOFFICIAL COMMUNITY HELPER · 0.1.0 BETA 1

Middle-earth,
on your Mac.

Install Third Age: Total War 3.2 using your own Medieval II game and the original mod downloads.

Before you begin

  • macOS 12 or later and the native Mac Steam version of Medieval II: Total War with Kingdoms. Open the original game once first.
  • 10 GB free on the game's drive, plus room for the downloads.
  • The two files from Gigantus's full Third Age 3.2 compilation:
    TATW 3.2 part 1 of 2.exe
    TATW 3.2 part 2 of 2.exe

Follow that guide's Total War Center link for download mirrors. The older 3.0 downloads and separate 3.2 patch are different packages. Divide and Conquer and Reforged are also different editions. This helper checks for the exact supported files; don't run the .exe files yourself.

Install in a few steps

  1. Unzip the helper release. Move Third Age for Mac.app into Applications, or an Applications folder in your home folder.
  2. Open the helper. This beta has not been notarized by Apple. If macOS blocks opening it, review System Settings → Privacy & Security → Open Anyway after the first attempt. Only approve an app you trust.
  3. Check Find your game. If needed, use Choose… to select the Medieval II Total War folder inside your Steam library's steamapps/common folder.
  4. Click Select files…. Hold Command to select both Third Age downloads together.
  5. Click Install Third Age. The helper checks the downloads, extracts the mod, and verifies its files. Let it finish. Cancel removes the temporary installation.

Enter Middle-earth

  1. Open Steam and sign in.
  2. Quit Medieval II completely if it is already open.
  3. Click Play Third Age in the helper, then Play in the Medieval II launcher.
  4. Start a new single-player campaign. Allow extra time on the first load while the game builds map and sound files.

The Desktop shortcut button makes an alias to this helper. Keep the app in its chosen folder after creating the shortcut.

If the original game opens

Quit Medieval II. In its launcher, choose Advanced, enable Advanced Options, and enter exactly:

--features.mod=mods/third_age_3

Then click Play. Turn this override off when returning to the original game or another mod such as Stainless Steel.

Common questions

Will this replace my other mods?

The helper adds its own third_age_3 folder. Existing game files, other mod folders, and saved campaigns stay in place. An existing Third Age folder will not be replaced or upgraded.

The download was rejected.

Check that you selected the exact two files above. Part 1 is 1,835,183,234 bytes and part 2 is 2,059,165,989 bytes. Their SHA-256 checksums are in the source README. A renamed or incomplete download will still be rejected.

The game folder cannot be used.

Choose the native Mac game folder with both the game app and Medieval2Data inside it. Kingdoms must be installed. Use a Steam library your Mac account can write to.

A custom settlement battle behaves strangely.

The mod team recommends 1-vs-1 custom battles for most custom settlements, which were designed for the campaign. See the original known issues.

What has been tested?

The installation approach was reported working by an Apple Silicon player. The automated installer passed a full test with both real downloads and 18,961 publisher checksum checks. It also passed cancellation and existing-mod preservation tests.

This is an early beta. Intel gameplay, older macOS versions, long campaigns, multiplayer, and every custom settlement have not been verified. The app contains both Intel and Apple Silicon binaries. Windows cutscenes are not converted; movie behavior needs further testing.

How do I report a problem?

Use the project's GitHub Issues page. Include your Mac chip, macOS version, helper version, exact error, and steps to reproduce. Say whether the failure happened during installation, launch, campaign, or battle. Hide personal information in screenshots.
